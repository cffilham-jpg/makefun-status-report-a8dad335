## Entry

> I rebuilt the task from memory after deleting it, and it is now 40% better and 100% not what you asked for.

## How it works

`main.py` writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `out`), with no trailing newline. Run it with `python3 main.py`.
